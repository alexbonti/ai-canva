AI-Assisted Software Project · Individual Project · Sprint pack

Sprint Tasks — 3 Weeks, 30 Hours

"One Student, One Box": the whole project in a three-week sprint, 10 hours per week, with the research (70% of the mark) spread across all three weeks.
Sprint: 3 weeks
Per week: 10 h
Total: 30 h
Must-do: 6 h/week
Weighting: Research 70% · Build 30%
Everything here maps onto the brief (brief.md): the same three deliverables, the same rubric, no extra marks. The app already runs — npm run dev works — so no setup time is budgeted anywhere below.

1. The sprint at a glance

WeekFocusExit — the week is done when…
Week 1Choose it, prove you need it, register itBox locked · research question written · 3 annotated sources · box registered in types.ts with a PR open · demo pipeline sketched on a board
Week 2Make it runPrompt templated · runBox branch produces real output · the demo pipeline runs end-to-end · empty/error paths handled · guardrails tested · report sections 1–2 drafted
Week 3Justify it, demo itFull 2,000–2,500 word report · rehearsed 5-minute demo · box connected into the class mega-pipeline · reflection submitted

No model call is required in Week 1. That is deliberate: the box earns its 30% in Week 2, and the report that earns the other 70% is written across all three weeks.

2. How the hours are cut

MarkerMeaning
🔴Must — the week fails without it (6 h)
🟡Should — finish these in a normal week (3 h)
🔵Stretch — the last hour (1 h)
The cut line: if you only get ~6 hours in a week, do the 🔴 rows and nothing else — and tell your instructor which rows you traded off, rather than reporting "10 hours" with the must-dos unfinished. Each week totals exactly 10 h (6 🔴 + 3 🟡 + 1 🔵); the three weeks total 30 h.

One thing to settle with your instructor: the brief's §4 labels C as "(30%)" on top of A's 30% and B's 70%, which adds to 130%. The rubric adds to exactly 100% (Build 15+10+5, Research 15+15+15+10+10+5), so the demo is already inside the build mark and the "30%" on C is a duplicate. Treat the rubric as authoritative unless you are told otherwise.
